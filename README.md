# 焰火 · 3D 烟花模拟器

原生 WebGL2 + Web Audio 实现的三维烟花模拟器。零依赖、无构建，双击 `index.html` 即可运行（或用任意静态服务器，如 `python -m http.server`）。需要支持 WebGL2 的浏览器（新版 Chrome / Edge / Firefox）。

## 2.0 相比 1.0

| | 1.0 | 2.0 |
|---|---|---|
| 空间 | 二维画布，球面只是投影出来的假象 | 真三维场景，可任意环绕、俯视、推拉 |
| 物理 | 像素单位、逐帧乘一个衰减系数 | 米/秒/千克真实单位，二次空气阻力、风切变、燃烧失重 |
| 弹道 | 飞到点击高度就炸 | 按弹径算出膛速度与引信时间，打靶法求解弹道 |
| 拖尾 | 画布残影 | 数十万颗独立火星，按黑体辐射从亮黄冷却到暗红 |
| 画面 | 加法混合 | HDR 渲染、辉光、ACES 色调映射、水面平面反射、受光硝烟 |
| 声音 | 即时播放 | 声速延迟、距离衰减、空气吸收、声像、混响 |
| 弹种 | 11 种 | 23 种（20 种礼花弹 + 3 种地面效果） |

## 功能

- **23 种弹种**，每种都按真实的装药结构建模：
  - 球形：牡丹（含变色）、菊花（含菊先）、垂柳、锦冠、芯入（八重芯）、双色、幻彩
  - 造型：环形（土星 / 原子 / 同心环）、心形、笑脸、五角星
  - 特效：棕榈、十字破、千轮、爆裂、频闪、蜂群、落叶、瀑布、雷鸣
  - 地面：彗星、地雷花、喷泉
- **三种模式**
  - 手动燃放：点击夜空任意位置，礼花弹会从驳船出膛并恰好飞到那里开花。
  - 布局编排：点击水面布置炮位（右键删除），齐射 / 顺序播放；内置扇形齐射、波浪列阵、中心千轮、彗星对射四个预设。
  - 自动表演：开场 → 随机段落（单发、齐射、追逐、扇面、垂柳、造型、爆裂、千轮）→ 压轴齐放，循环不重样。所有礼花弹按"开花时刻"编排，提前引信时间点火，不同口径才能踩在同一拍上。
- **三维镜头**：拖拽旋转、滚轮推拉、右键（或 Shift）拖拽平移；六个机位预设（观众席 / 近景仰望 / 航拍 / 俯瞰 / 侧翼 / 湖畔远眺）与自动环绕巡航。
- **时间控制**：0.05×–1.5× 流速，以及"冻结时间"——定格后绕着烟花转一圈，能直观看到环形弹是一个平面、心形弹侧面是一条线。
- **环境**：风速风向（影响弹道、火星与硝烟）、水面倒影、硝烟、烟花对天空 / 城市 / 水面的照明。
- **可调规格**：弹径 3–12 寸（面板实时显示对应的开花直径、出膛速度、引信时间）、炸高、10 套基于金属焰色的配色。
- **遥测 HUD**：右下角显示每发弹的实际炸高、开花直径、出膛速度与引信时间。
- **烟花原理面板**：烟花弹剖面图、金属焰色表，以及当前弹种的成形原理。

## 建模要点

**弹道**。礼花弹按口径算出直径、质量与阻力系数 `k = ½ρ·Cd·A/m`，运动方程为 `a = -k|v|v + g`。竖直发射时出膛速度与到顶时间有解析解；朝任意点发射时用打靶法迭代求初速。得到的数值与实物相符：6 寸弹出膛约 86 m/s、引信 5.5 s、炸高 186 m；12 寸弹出膛约 110 m/s、引信 7.5 s、炸高 330 m。引信带 ±2% 的制造公差。

**开花**。药珠用斐波那契格点均匀铺在球壳上（好的礼花弹星点分布均匀，纯随机会成团）。每种弹用三个量描述：燃尽半径 `R`、燃烧时间 `T`、阻力形状 `β = k·R`。由二次阻力下的位移公式 `R = ln(1 + k·v₀·T)/k` 反解出初速 `v₀`，所以"先猛然炸开、再缓缓停住"的节奏是算出来的而不是调出来的。星体燃烧时变小，阻力系数随之增大。造型弹逐星反解初速，使每颗星在燃尽时刻恰好到达图案位置——因此刚炸开时轮廓偏圆，后段才显形，与实物一致。

**拖尾火星**。数量太大（压轴时数十万颗），采用无状态粒子：出生时把位置、速度、时刻等 16 个 float 写入环形缓冲，之后的轨迹由顶点着色器按线性阻力的闭式解 `p(t) = p₀ + vₜ·t + (v₀ - vₜ)(1 - e^{-kt})/k` 直接算出，CPU 不再碰它。炭火余烬按黑体辐射着色，温度从约 2400 K 冷却到 1100 K，亮度随温度的幂次衰减。按发射速率预估缓冲占用并自动限流，以亮度补偿。

**渲染**。场景渲染到半浮点 HDR 帧缓冲。粒子是沿速度方向拉伸的公告板（运动模糊）；小于一个像素的粒子放大到最小像素并等比压低亮度，保证远近能量一致。水面用镜像相机做平面反射，近处解析波浪、远处把小于像素足迹的波转为统计粗糙度并做纵向拉伸，形成长条倒影。每次爆炸是一个动态点光源，照亮硝烟、楼群、水体，并在天空着色器里做前向散射辉光。最后经 6 级辉光金字塔与 ACES 色调映射输出——亮处的橙色余烬自然过曝成金色。

**声音**。爆声按"距离 ÷ 声速"延迟（慢动作时同步拉长），并随距离衰减、滤掉高频；左右声像取决于爆点在画面中的方位；合成的混响模拟水面与楼群间的回荡。

## 性能

画质分低 / 中 / 高 / 极致四档（火星缓冲 14 万–130 万、渲染分辨率上限 1×–2×）。帧率不足时自动降低火星发射率，仍不够则逐级降低渲染分辨率。

## 文件结构

```
index.html        页面结构 + 原理面板
css/style.css     界面样式
js/core.js        数学工具、金属焰色、配色方案、弹径规格
js/shaders.js     全部 GLSL 着色器
js/sim.js         物理仿真：弹道、星体、火星环形缓冲、硝烟、光源、定时事件
js/shells.js      23 种弹种的装药结构与二段效果
js/camera.js      环绕镜头与机位预设
js/renderer.js    WebGL2 渲染管线
js/show.js        自动表演编导
js/audio.js       空间音效合成
js/main.js        主循环、输入、模式与界面绑定
```

调试接口：控制台可用 `window.__fw`（`sim` 仿真 / `cam` 镜头 / `renderer` 渲染器 / `state` 状态 / `step(dt, n)` 手动推进仿真）。
