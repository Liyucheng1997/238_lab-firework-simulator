# 焰火 · 烟花模拟器

纯原生 HTML5 Canvas + Web Audio 实现的烟花模拟器，零依赖，双击 `index.html` 即可运行（或用任意静态服务器，如 `python -m http.server`）。

## 功能

- **11 种真实弹种**：牡丹、菊花、垂柳、锦冠、环形、双层芯、心形、蜂群、频闪、十字破、棕榈，每种都基于真实烟花的星点排列方式建模。
- **三种模式**
  - 手动燃放：点击夜空任意位置发射（空格键快速发射）。
  - 布局编排：在地面点击布置炮位（右键删除），支持齐射 / 顺序播放 / 间隔调节，内置扇形齐射、波浪列阵、中心千轮三个预设。
  - 自动表演：随机编排的持续烟花秀。
- **烟花原理面板**：烟花弹剖面图（发射药 → 延时引信 → 开包药 → 效果药珠），金属焰色反应发色表（锶红 / 钡绿 / 铜蓝……），以及每种弹种的成形原理说明。
- **可调参数**：弹径（2–10 寸）、升空高度、8 套配色（对应真实金属焰色）、音效开关、空间光照开关。
- **合成音效**：升空啸声、爆炸低频冲击、噼啪声均由 Web Audio 实时合成，无音频文件。

## 技术要点

- 双画布分层：`bgCanvas` 每帧重绘夜景（星空 / 月亮 / 城市剪影），`fxCanvas` 用 `destination-out` 低透明度衰减实现粒子拖尾，`lighter` 加法混合实现辉光。
- 物理模拟：重力 + 空气阻力 + 球面均匀分布采样；火箭按抛体运动计算初速，速度耗尽即在顶点引爆（对应延时引信原理）。
- 类型行为系统：粒子支持洒金（glitter）、频闪（strobe）、乱舞（wiggle）、二次分裂（crossette）、颜色燃尽衰变（fade）等可组合属性。

## 文件结构

```
index.html        页面结构 + 原理面板 SVG
css/style.css     深色玻璃拟态 UI
js/audio.js       Web Audio 合成音效
js/fireworks.js   粒子物理 + 11 种弹种的爆炸构造
js/main.js        渲染循环、夜景背景、模式与交互
```

调试接口：控制台可用 `window.__fw`（`sys` 粒子系统 / `state` 状态 / `step()` 单步驱动一帧）。
